# HUMAN_PROTOCOL.md — протокол человека в подсессии

> **Назначение:** что делает человек в подсессии. Всё остальное —
> Кило Code (исполнитель) и Кило Ask (аудитор).
> **Статус:** рабочий документ (уровень 4).
> **Модель:** оба режима — DeepSeek V4.1 Flash. Меняются только права:
> Ask не пишет файлы и не коммитит, Code пишет и коммитит с разрешения.

---

## 1. Кто есть кто

| Роль | Кто | Режим | Что делает |
|---|---|---|---|
| **Координатор** | Кило Code | Code mode | Ведёт подсессию: план, код, гейты, интерпретация отчётов аудитора, коммит |
| **Аудитор** | Кило Ask | Ask mode | Проверяет план/код по `AUDIT_PROMPTS.md`, отдаёт отчёт |
| **Человек** | Ты | — | Переключаешь режимы, копируешь текст, даёшь команды «переходи к шагу N» |
| **Управляющий** | DeepSeek | — | Тупики, архитектурные вопросы, правка инструкций |

**Важно:** режима `Orchestrator` в Kilo нет (deprecated). Роль «Оркестратора»
исполняет **Code mode**, читая `coordinator_prompt.md`. Переключение
Code ↔ Ask — **всегда человек**, инструментальной автоматизации между
ними нет.

---

## 2. Твои действия (и только они)

Ты — **переключатель режимов и курьер отчётов**. Ты не интерпретируешь
отчёты, не решаешь «чинить или нет», не правишь код. Это делает Кило
Code по `coordinator_prompt.md`.

---

## 3. Цикл подсессии

### Старт

1. Открой Kilo в **Code mode**.
2. Напиши: `Начинаем подсессию <N>. Шаг 1 — план.`
3. Кило отдаёт план → **стоп** (по инструкции).

### Шаг 1 → 2 (переключение на аудит плана)

4. Скопируй план.
5. Переключи Kilo в **Ask mode**.
6. Вставь: `Аудит плана подсессии <N>. План: <текст плана>.`
7. Ask отдаёт отчёт.

### Шаг 2 → 3 (возврат в Code)

8. Скопируй отчёт Ask.
9. Переключи Kilo в **Code mode**.
10. Вставь: `Отчёт аудита плана: <текст>. Если APPROVE — переходи к
    шагу 3 (код). Если CHANGES REQUIRED — правь план, отдай правку.
    Если STOP — отдай отчёт и жди.`
11. **Кило сам решает.** Ты не интерпретируешь.

### Шаг 3 → 4 (переключение на аудит кода)

12. Кило отдаёт код + гейты → **стоп**.
13. Скопируй отчёт о коде (файлы, гейты, отклонения).
14. Переключи в **Ask mode**.
15. Вставь: `Аудит кода подсессии <N>. План: <текст плана>. Отчёт
    о коде: <текст>.`
16. Ask отдаёт отчёт.

### Шаг 4 → 5 (возврат в Code)

17. Скопируй отчёт Ask.
18. Переключи в **Code mode**.
19. Вставь: `Отчёт аудита кода: <текст>. Если APPROVE — шаг 5 (коммит)
    по плану. Если CHANGES REQUIRED — правь указанные пункты, гейты
    заново, потом снова шаг 4. Если STOP — не коммить, отдай отчёт.`
20. **Кило сам решает.** Ты не интерпретируешь.
21. Кило делает гейт индекса (`git diff --cached --name-only` — ровно
    заявленные пути, ни одного из `backend/src/**`, `.kilo/`,
    `coordinator_prompt.md`, `<план>.md`), коммитит, отдаёт
    `git log --oneline -1` + `git status --short`.

### Конец

22. Подсессия закрыта. Скопируй `git log --oneline -1` — это отчёт
    о закрытии (при необходимости передай Управляющему).

---

## 4. Что ты НЕ делаешь

- Не читаешь отчёт аудитора «по существу» — это делает Кило Code.
- Не решаешь «это блокер или мелочь» — это делает Кило Code по вердикту Ask.
- Не правишь код руками (если Кило завис — зовёшь Управляющего).
- Не проверяешь `git diff --cached` сам — это делает Кило Code
  (гейт индекса в `coordinator_prompt.md`).
- Не запускаешь аудит «сам у себя» в Code mode — Ask только отдельной сессией.

---

## 5. Когда звать Управляющего (DeepSeek)

Только в трёх случаях:

1. **Кило завис** — не отдаёт шаг, зациклился, теряет контекст,
   компакция съела состояние.
2. **Кило предлагает решение, противоречащее `MASTER_SPEC.md` или
   `DOMAIN.md`** — архитектурный арбитраж.
3. **Нужно поменять процесс** — не разовую подсессию, а правило
   (`coordinator_prompt.md`, `HUMAN_PROTOCOL.md`, `MASTER_SPEC.md`).

Во всех остальных случаях Кило Code + Кило Ask справляются сами.

## 6. Шпаргалка (что писать в каждом режиме)

| Режим | Текст |
|---|---|
| **Code** (старт) | `Начинаем подсессию <N>. Шаг 1 — план.` |
| **Ask** (аудит плана) | `Аудит плана подсессии <N>. План: <текст>.` |
| **Code** (возврат после аудита плана) | `Отчёт аудита плана: <текст>. APPROVE → шаг 3. CHANGES REQUIRED → правка плана. STOP → жди.` |
| **Ask** (аудит кода) | `Аудит кода подсессии <N>. План: <текст>. Отчёт о коде: <текст>.` |
| **Code** (возврат после аудита кода) | `Отчёт аудита кода: <текст>. APPROVE → шаг 5 (коммит). CHANGES REQUIRED → правка, гейты, снова шаг 4. STOP → не коммить.` |
| **Code** (если завис) | Стоп → зовёшь Управляющего (DeepSeek). |
