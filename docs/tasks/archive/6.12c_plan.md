## 8 эндпоинтов

**Файл:** `backend/src/adapters/api/routes/rfis.py`

**Важно:** `/proposals` и `/from-proposal` должны быть объявлены **ДО** `/{id}` (FastAPI match-first, иначе `{id}` перехватит `proposals`).

### Порядок объявления (spec_week_4 §7):

| # | Method | Path | Response | Service | Error handling |
|---|--------|------|----------|---------|----------------|
| 1 | GET | `/projects/{project_id}/rfis/proposals` | `list[RfiProposal]` | `RfiProposalService.propose_rfis(project_id)` | — |
| 2 | POST | `/projects/{project_id}/rfis/from-proposal` | `RfiRead` (201) | `RfiService.create(...)` | `ValueError` → 400, `IntegrityError` → 409 |
| 3 | GET | `/projects/{project_id}/rfis` | `list[RfiRead]` | `RfiService.list_by_project(project_id)` | — |
| 4 | POST | `/projects/{project_id}/rfis` | `RfiRead` (201) | `RfiService.create(...)` | `ValueError` → 400, `IntegrityError` → 409 |
| 5 | GET | `/rfis/{id}` | `RfiRead` | `RfiService.get(id)` | not found → 404 |
| 6 | PATCH | `/rfis/{id}` | `RfiRead` | `RfiService.update(id, ...)` | `ValueError` → 400, `IntegrityError` → 409, not found → 404 |
| 7 | DELETE | `/rfis/{id}` | 204 | `RfiService.delete(id)` | `ValueError` → 400 |
| 8 | POST | `/rfis/{id}/escalate` | `RfiRead` | `RfiService.escalate(id)` | `ValueError` → 400 |

### Детали эндпоинтов

**#1 GET /proposals:**
```python
@router.get("/projects/{project_id}/rfis/proposals", response_model=list[RfiProposal])
async def list_rfis_proposals(project_id: UUID, service: RfiProposalServiceDep):
    return await service.propose_rfis(project_id)
```

**#2 POST /from-proposal:**
```python
@router.post("/projects/{project_id}/rfis/from-proposal", response_model=RfiRead, status_code=201)
async def create_rfi_from_proposal(
    project_id: UUID,
    payload: RfiProposalApprove,
    service: RfiServiceDep,
):
    # formulation → title (RfiProposalApprove.formulation = Task.title)
    # rationale → description (RfiProposalApprove.rationale = Task.description)
    try:
        task = await service.create(
            project_id=project_id,
            title=payload.formulation,
            rfi_cause_decision_id=payload.rfi_cause_decision_id,
            rfi_due_date=payload.rfi_due_date,
            rfi_state=payload.rfi_state,
            description=payload.rationale,
        )
    except ValueError as err:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST, detail=str(err)
        ) from err
    except IntegrityError as err:
        raise HTTPException(
            status_code=status.HTTP_409_CONFLICT, detail="conflict"
        ) from err
    return RfiRead.model_validate(task, from_attributes=True)
```

**#3 GET /projects/{id}/rfis:**
```python
@router.get("/projects/{project_id}/rfis", response_model=list[RfiRead])
async def list_rfis(project_id: UUID, service: RfiServiceDep):

    return [RfiRead.model_validate(r, from_attributes=True) for r in rfis]
```

**#4 POST /projects/{id}/rfis:**
```python
@router.post("/projects/{project_id}/rfis", response_model=RfiRead, status_code=201)
async def create_rfi(
    project_id: UUID,
    payload: RfiCreate,
    service: RfiServiceDep,
):
    try:
        task = await service.create(
            project_id=project_id,
            title=payload.title,
            rfi_cause_decision_id=payload.rfi_cause_decision_id,
            rfi_cause_goal_id=payload.rfi_cause_goal_id,
            rfi_due_date=payload.rfi_due_date,
            rfi_state=payload.rfi_state or RfiState.OPEN,
            deadline=payload.deadline,
            assignee_id=payload.assignee_id,
            is_complex=payload.is_complex,
        )
    except ValueError as err:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST, detail=str(err)
        ) from err
    except IntegrityError as err:
        raise HTTPException(
            status_code=status.HTTP_409_CONFLICT, detail="conflict"
        ) from err
    return RfiRead.model_validate(task, from_attributes=True)
```

**#5 GET /rfis/{id}:**
```python
@router.get("/rfis/{rfi_id}", response_model=RfiRead)
async def get_rfi(rfi_id: UUID, service: RfiServiceDep):
    task = await service.get(rfi_id)
    if task is None:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail=f"RFI {rfi_id} not found",
        )
    return RfiRead.model_validate(task, from_attributes=True)
```

**#6 PATCH /rfis/{id}:**
```python
@router.patch("/rfis/{rfi_id}", response_model=RfiRead)
async def update_rfi(
    rfi_id: UUID,
    payload: RfiUpdate,
    service: RfiServiceDep,
):
    data = payload.model_dump(exclude_unset=True, by_alias=False)
    try:
        task = await service.update(rfi_id, **data)
    except ValueError as err:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST, detail=str(err)
        ) from err
    except IntegrityError as err:
        raise HTTPException(
            status_code=status.HTTP_409_CONFLICT, detail="conflict"
        ) from err
    if task is None:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail=f"RFI {rfi_id} not found",
        )
    return RfiRead.model_validate(task, from_attributes=True)
```

## Проверка по факту

- `RfiService.create` принимает `title` (не `formulation`) — маппинг в роуте `from-proposal`
- `RfiService.create` принимает `description` — маппинг `rationale → description`
- `RfiService.get` возвращает `Task | None` — None → 404
- `RfiService.update` принимает keyword-only аргументы (`**data` из `model_dump(exclude_unset=True)`)
- `RfiService.escalate` принимает `task_id: UUID`
- `RfiRead.model_validate(task, from_attributes=True)` — маппинг Task → RfiRead
- `RfiState.OPEN` — enum value, используется как дефолт в `RfiCreate`
- `IntegrityError → 409` — по паттерну decisions.py
- `HTTPException` — именованные параметры + `from err` + `status.HTTP_*` константы
- Секционные комментарии: `# ---------- Proposals (ДО /{rfi_id}!) ----------`
