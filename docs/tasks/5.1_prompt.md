## Цель

Создать доменную модель + SQLAlchemy-модели + Alembic-миграцию + сиды
для 4 сущностей ГОСТ-документов:

1. **DocumentType** — справочник типов (code, name, gost_code).
2. **Document** — карточка документа (ГОСТ Р 21.101-2026).
3. **DocumentVersion** — версия файла (hash, size, is_current).
4. **DocumentLink** — связь между документами.

**НЕ делаем в этой сессии:** DTO, порты, репозитории, сервисы, API, тесты, frontend.

## Огранижения

### Архитектура

- **Домен чистый:** `backend/src/domain/**` не импортирует FastAPI / SQLAlchemy / Pydantic.
- **Зависимости:** adapters → application → domain. Никогда наоборот.
- **Save через merge:** репозитории будут в Сессии 5.2.
- **session.commit() вручную — нельзя.** Это делает `get_db_session`.

### TimestampMixin

- **`DocumentModel`** — использует `TimestampMixin` (как `EntityTypeModel`).
- **`DocumentTypeModel`** — БЕЗ TimestampMixin (только `created_at`).
- **`DocumentVersionModel`** — БЕЗ TimestampMixin (только `uploaded_at`).
- **`DocumentLinkModel`** — БЕЗ TimestampMixin (только `created_at`).

### Особые решения

- **`current_version_id` — не FK.** Осознанное решение: избегаем циклической
  зависимости documents → document_versions → documents.
- **`document_type_id` — обязательный** в домене (без `| None`). Тип документа —
  обязательный атрибут ГОСТ-документа.
- **`link_type: Mapped[str]`** (не `DocumentLinkType`) — Enum только в домене, конвертация в репозитории (Сессия 5.2).
- **`guid` — unique=True**, отдельный btree-индекс НЕ создавать (unique уже даёт индекс).
- **`postgresql_where=text("is_current = TRUE")`** — именно `text()`, не строка.
- **`onupdate=func.now()`** — через TimestampMixin (не `datetime.now`).

### Сиды

- Через `op.execute("INSERT ... ON CONFLICT (code) DO NOTHING")`.
- 8 записей document_types.

### down_revision

- **НЕ указывать вручную.** `alembic revision --autogenerate` подставит текущий head сам.
